# 第 12 讲 Backend 作业：删除账号与文件

姓名：谭翔之  
班级：无57班

## 实现内容

- `GET /user/delete`：使用 Authorization 中的 JWT 用户 UUID 删除当前用户；数据库外键级联删除其会议关系与消息。
- `POST /file/delete`：接收 `{ room, filename }`，校验 UUID、阻止路径穿越、确认用户属于会议后删除该会议目录中的文件。
- 两个接口都检查参数、认证、资源是否存在并返回清晰的 HTTP 状态码；数据库或文件系统异常返回 500，不把内部堆栈泄露给客户端。
- 前端用户卡片加入“删除账号”二次确认；文件共享列表加入删除按钮，成功后立即更新列表。

## 安全设计

删除账号只使用令牌中的用户 UUID，不接受客户端传入的用户 ID。删除文件要求用户是目标会议成员，并拒绝包含目录分隔符或空字节的文件名；解析后的目标路径必须位于该会议目录内。

## 验证清单

在配置 `.local.env`、Hasura 和文件目录后，可使用登录得到的 Bearer token 验证：未登录返回 401、缺少参数返回 422、非会议成员删除返回 403、不存在资源返回 404、成功删除返回 204。删除文件后再次列出文件应不再出现该文件，删除账号后应清除对应数据库记录并退出前端。
